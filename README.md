# SafeScan AI

An AI-powered Digital Threat Intelligence platform for analyzing
suspicious emails, URLs, and QR codes.

## Features

- MailGuard AI — Email threat analysis
- URLShield AI — Suspicious URL analysis
- QRShield AI — QR code destination analysis
- Feedback and review management
- Privacy and terms information

## Tech Stack

- Python
- Flask
- HTML, CSS, JavaScript
- SQLite

## Getting Started

1. Clone the repository:

   git clone https://github.com/vignesh-techforge/SafeScan_AI.git

2. Open the project folder:

   cd SafeScan_AI

3. Install dependencies:

   py -m pip install -r requirements.txt

4. Run the application:

   py main.py

5. Open the local URL shown in the terminal
   in your web browser.

## Project Purpose

SafeScan AI helps users examine potential digital threats
through email, URL, and QR code analysis.
